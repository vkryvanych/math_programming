# Моделювання кінематики прямолінійного руху
Програмний продукт для візуалізації траєкторії руху матеріальної точки на координатній площині з можливістю завдання початкових параметрів. 

## Функціонал
* Введення початкових координат ($X_0$, $Y_0$), кута напрямку, початкової швидкості та прискорення. Також є можливість змінювати колір графіка.
* Автоматична нормалізація введеного кута.
* Динамічна побудова траєкторії руху на елементі `<canvas>` у вигляді штрих-пунктирної лінії.
* Візуалізація декартової системи координат (4 чверті).

## Технології

* **CSS**
